# PadTube（OPPO Pad 平板版）

PadTube 是参考仓库根目录的 YouTube Clear 桌面版，为 Android 平板单独建立的 APK 项目。首版重点是 OPPO Pad 横屏观看体验，不需要读取相册或文件权限。

## 已实现

- 无登录清爽模式：保留网页广告清理与平板播放界面
- 登录观看模式：使用系统 Chrome / Custom Tab，支持安全登录 Google 账号
- 平板横屏工具栏：后退、前进、首页、刷新
- 电脑版 / 手机版网页一键切换
- 视频全屏时自动隐藏工具栏和系统栏，并切换到横屏
- 硬件加速与自动播放
- 网络域名拦截、页面广告元素隐藏、播放器广告自动跳过三层处理
- 外部网站默认交给系统浏览器打开
- 旋转屏幕时保留当前网页和播放状态
- 不申请存储、相机、麦克风或定位权限

## 1.2.0 平板显示优化

- 横屏观看页自动使用宽屏播放器，修复移动版页面只占左侧、右侧大面积留白
- 视频始终按原始比例完整显示，不拉伸；比例不同时保留黑边
- 全屏时持续恢复 ColorOS 沉浸模式，并避开顶部系统手势安全区
- 修复 OPPO Pad 全屏播放器右上角设置按钮难以点击的问题

## 1.2.1 登录保持优化

- 首次选择“登录观看”后记住登录模式，下次启动自动进入登录环境
- 固定复用同一个系统浏览器，避免不同浏览器之间登录状态不互通
- 应用进入后台或退出时主动持久化 WebView Cookie

## 1.7.4 广告结束卡片

- 部分广告播完后会显示带“跳过”按钮的结束卡片，YouTube 不响应脚本点击，之前每次要等约 7 秒。现在由 App 在跳过按钮上模拟一次真实触摸，立即关闭
- 只有按钮位于触摸点最上层时才会触摸，不会点到广告本身；最快约 1 秒一次
- 仅 PadTube；PadMusic 未改动

## 1.7.3 耗电与播放体验

- 暂停后留在后台：PadMusic 30 秒后暂停网页，PadTube 仍是立即暂停；两者 10 分钟后都会关闭通知和服务，回到 App 后可继续播放
- PadTube 和 PadMusic 不再同时出声，一个开始播放时另一个自动暂停（电话等其他 App 的音频焦点尚未处理）
- 拔出耳机或断开蓝牙时自动暂停，不再转为外放
- 播放时保持 CPU 和 Wi-Fi 唤醒，暂停时释放，减少锁屏卡顿（PadTube 新增，PadMusic 增加 Wi-Fi）
- 清理脚本只响应新元素和播放器内的变化，兜底定时器从每 0.5 秒改为约 3 秒一次，跳广告时才高频运行
- 通知栏只在歌曲信息或播放状态变化时刷新
- 信息流里静音自动播放的预览不再被当作正在播放；静音观看的视频切到后台也会暂停
- 加载失败的提示不再被后续加载进度清掉；重试、刷新、回首页或打开其他页面时才消失
- 输入时键盘不再遮挡页面；修改显示大小或字体大小不再中断播放

## 1.7.2 行为修复

- 播放中在根页面按返回键，改为退到后台继续播放；没有播放时仍正常退出
- 清理脚本只在 YouTube 页面的顶层框架运行，不再进入 Google 登录页和直播聊天等 iframe
- 恢复页面失败时回到首页，不再白屏
- PadMusic 切到后台时保存 Cookie，降低登录状态丢失的可能
- 封面下载失败时不再显示上一首的封面，并会重试；过大的封面会先缩小
- 移除不再生效的“记住登录浏览器”逻辑，自动打开登录浏览器统一由菜单的“自动登录”开关控制；补上 Android 11 以上检测 Custom Tabs 浏览器所需的声明

## 1.7.1 稳定性与正式签名

- WebView 渲染进程崩溃或被系统回收时不再闪退，自动重建页面并回到原页面；若 10 秒内再次崩溃则回到首页
- 后台开始播放时，PadMusic 不再因系统限制启动前台服务而闪退
- 外部链接收紧：iframe 不再拉起其他 App；只有点击的网页、邮件链接才会离开 App，页面脚本的自动跳转和其他协议一律阻止
- 含未编码 `|`、`^`、`"` 的 YouTube 链接留在 App 内，不再被误判为外部链接
- 发布包改为 Release 构建并使用自己的签名。**从旧版升级需要先卸载一次（证书不同），之后要重新登录**

## 1.7.0 合并 PadMusic（YouTube Music）

- 安装后桌面出现两个图标：「PadTube」看视频，「PadMusic 音乐」听 YouTube Music
- 两者是同一个 App，共享登录：PadTube 已登录的 Google 账号在 PadMusic 里直接可用（Google 禁止在 WebView 内新登录，独立的 PadMusic 无法登录）
- PadMusic 保留去广告、锁屏 / 后台播放、锁屏歌曲信息与上一首 / 下一首控制、手机自适应布局
- 两个图标是独立任务，划掉其中一个不会停止另一个的播放
- 源码位于 `app/src/main/java/com/edwyn/padtube/music/`；原 `oppo-pad-music` 项目不再单独发布

## 1.6.0 手机适配（如 Samsung Galaxy S25 Ultra）

同一个 APK 同时支持平板和手机，按屏幕最小宽度自动判断（< 600dp 视为手机）：

- 手机默认打开手机版网站，平板保持电脑版；手动切换「电脑版 / 手机版」后会记住选择
- 手机全屏播放横屏视频时自动转为横屏（即使开了方向锁定），竖屏视频 / Shorts 保持竖屏
- 手机版网站打开视频不再默认静音
- 手机版网站在画中画 / 分屏时不再被 YouTube 自动暂停，画中画小窗只显示视频

## 1.5.1 锁屏继续播放

- 锁屏或切到后台时，正在播放的视频继续播放（声音不中断）
- 锁屏界面与通知栏显示播放 / 暂停控制，点通知回到 PadTube
- 没有在播放时，切到后台仍会暂停 WebView 省电；关闭画中画小窗仍会暂停

## 1.5.0 播放与清理优化（OPPO Pad 实机验证）

- 修复 WebView 中 CSS `100vh` 恒为 0 的问题（Compose 默认 WRAP_CONTENT 布局参数导致），播放器从 240px 高恢复为满宽 16:9
- 清理脚本改为页面开始加载时注入，首页信息流广告不再先闪现几秒
- 隐藏整张广告卡片与播放页赞助商广告面板，不再留下空白卡位
- 工具栏画中画不再黑屏，小窗内只显示视频；关闭画中画小窗后自动暂停，不再后台出声
- 桌面版 UA 跟随系统 WebView 的真实 Chrome 版本
- 清理脚本合并 DOM 变动回调，降低浏览时的 CPU 占用
- 单页跳转后同步前进/后退按钮状态

## 用 Android Studio 构建

1. 用 Android Studio 打开本文件夹 `oppo-pad-video`。
2. 等待 Gradle 同步完成。
3. 选择 `Build > Build APK(s)`。
4. APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

命令行也可以运行：

```powershell
.\gradlew.bat test assembleDebug
```

## 构建发布包

日常安装用 Release 包：体积约为 Debug 包的十分之一，并且关闭了 WebView 远程调试。

1. 生成一次签名文件（放在项目根目录，已被 git 忽略）：

   ```powershell
   keytool -genkeypair -v -keystore padtube-release.jks -alias padtube -keyalg RSA -keysize 2048 -validity 10000
   ```

2. 复制 `keystore.properties.example` 为 `keystore.properties`，填入密码。
3. 运行下面的命令，APK 输出到 `release/PadTube-<版本号>.apk`：

   ```powershell
   .\gradlew.bat test archivePadTubeRelease
   ```

**务必把 `padtube-release.jks` 和密码备份到项目目录以外。** 丢失后已安装的 App 无法覆盖升级，只能卸载重装并重新登录。

## 安装到 OPPO Pad

1. 把构建好的 APK 传到平板（Release 包在 `release/`，Debug 包是 `app-debug.apk`）。
2. 在系统设置中允许当前文件管理器“安装未知应用”。
3. 点 APK 安装。
4. 无需账号时直接使用主页；需要订阅、历史和个性化推荐时，点右上角“登录观看”。

## 说明

- 这是个人使用的 WebView 客户端，不包含 YouTube 视频文件，也不提供下载功能。
- YouTube 页面或广告机制改版后，清理规则可能需要随之更新。
- Google 明确禁止在 Android WebView 内登录。PadTube 会拦截内嵌登录页面并打开官方支持的 Chrome Custom Tab。
- “登录观看”共享系统浏览器的 Google 登录状态，但浏览器安全隔离也意味着 PadTube 无法向该模式注入广告清理脚本。无登录清爽模式与登录观看模式是两个独立环境。
- 发布给其他人前，请更换正式签名、应用 ID，并自行确认 YouTube 服务条款与当地法规。
